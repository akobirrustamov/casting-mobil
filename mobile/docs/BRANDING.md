# Логотип и иконки

Последнее обновление: 13.08.2026

---

## Исходники

Лежат в `assets/brand/`, в сборку напрямую не идут:

| Файл | Что это |
|---|---|
| `logo.svg` | вектор, 5 КБ, 512×512 viewBox |
| `logo-source.png` | растр 4096×4096, прозрачный фон |

Знак: монограмма UZ с play-треугольником и киноплёнкой.
Градиент `#6F20FF → #A72DFF → #E33CFF` — попадает в Neon Purple / Magenta из ТЗ.

---

## Где какой формат

Правило простое: **везде, где можно, вектор; растр — только там, где система вектор не принимает.**

### SVG — внутри приложения

`src/components/ui/Logo.tsx`, через `react-native-svg-transformer`:

```tsx
import { Logo } from '@/components/ui/Logo';
<Logo size={72} />
```

Используется на экране входа. Дальше — хедер главной, splash-заглушки, пустые состояния.

Почему вектор: любой размер без замыливания, 5 КБ вместо 1.9 МБ, градиент остаётся живым.

### PNG — то, что рендерит система

Иконку приложения и splash рисует не React, а Android/iOS — там только растр. Сгенерированы из `logo-source.png` скриптом с обрезкой прозрачных полей:

| Файл | Размер | Куда |
|---|---|---|
| `icon.png` | 1024², фон `#07070D` | иконка приложения |
| `android-icon-foreground.png` | 1024², прозрачный, логотип 62% | adaptive icon |
| `android-icon-background.png` | 1024², сплошной `#07070D` | подложка adaptive icon |
| `android-icon-monochrome.png` | 1024², белый силуэт | themed icon Android 13+ |
| `splash-icon.png` | 1024², прозрачный | splash, ширина 180 |
| `favicon.png` | 96², фон `#07070D` | web |
| `logo-mark.png` | 512², прозрачный | запас, если где-то не подойдёт SVG |

Подобраны по правилам платформ: у iOS-иконки не должно быть прозрачности, у adaptive icon Android безопасная зона ~66% от стороны — поэтому логотип на переднем плане уменьшен до 62%, иначе края обрежет маской.

### JPEG — сайт и админка (`frontend/`)

Веб-часть живёт в другом дереве, но знак у неё тот же и берётся из **этого же** `logo-source.png`. Формат оставлен JPEG, потому что имена файлов уже разошлись по импортам, а прозрачность там не нужна: знак везде стоит в круглой или скруглённой рамке на тёмном.

| Файл | Размер | Куда |
|---|---|---|
| `frontend/public/logo.jpg` | 640², фон `#07070D` | favicon и apple-touch-icon |
| `frontend/public/logo.png` | 512², фон `#07070D` | `manifest.json` |
| `frontend/public/favicon.ico` | 16…256² | `/favicon.ico` |
| `frontend/src/pages/header/logo.jpg` | 640² | шапка бот-админки |
| `frontend/src/pages/header/logo1.jpg` | 1024² | шапка сайта и админки |
| `frontend/src/pages/footer/logo.jpg` | 640² | подвал |
| `frontend/src/pages/BotHeader/logo.jpg` | 640² | шапка бота |

Доля заполнения 68%: знак должен читаться в рамке 40×40 в шапке и при этом не упираться в края круга.

⚠️ Веб-сборка отдаётся из `classpath:/static/`, то есть логотип попадает к пользователю только после пересборки фронта — см. `server_config.md` §3.1. Поменять картинки и не пересобрать значит оставить на сайте старый знак.

## Пересобрать иконки

Если логотип поменяется — положить новый `assets/brand/logo-source.png` и прогнать скрипт генерации заново (он в истории задачи). Вручную ресайзить не нужно: важны и обрезка прозрачных полей, и разные доли заполнения для разных целей.

⚠️ Веб-файлы генерируются из того же исходника и **не** обновляются вместе с мобильными: 26.08.2026 знак поменяли, а сайт и админка до 09.09 ходили со старым золотым логотипом. Меняешь знак — проходи оба списка.

Splash настраивается плагином в `app.json`:

```json
["expo-splash-screen", {
  "image": "./assets/splash-icon.png",
  "backgroundColor": "#07070D",
  "imageWidth": 180
}]
```
