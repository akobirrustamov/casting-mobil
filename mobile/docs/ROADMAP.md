## 1. Что за продукт

UzCasting — мобильная платформа, объединяющая три вещи:

1. **Кастинг** — актёры, модели, блогеры и другие креаторы ведут профессиональное портфолио и подают заявки на роли.
2. **Премьеры** — платный эксклюзивный контент (сериалы, шоу, фильмы) по 5 000 сум за серию.
3. **Creator economy** — креатор заливает контент, получает долю с продаж и выводит деньги.

### Ядро монетизации (из ТЗ)

```
Блогер выкладывает 1-ю серию бесплатно на YouTube/Instagram
        ↓
CTA в конце видео: «Продолжение — на UzCasting за 5 000 сум»
        ↓
Пользователь покупает серию в приложении (Click / Payme / Uzum / UZCARD / Visa / MC)
        ↓
Платёж подтверждён → entitlement → защищённый плеер
        ↓
Revenue share 50/50 между креатором и платформой
```

Это главный сценарий приложения. Всё остальное — обвязка вокруг него.

- Spacing: система 8–16px
- Radius карточек: 14–22px (`rounded-card` = 16, `rounded-card-lg` = 22)

- Glow-эффекты в меру, без избыточных градиентов
- Цена и locked-статус видны с первого взгляда

## 6. Технический стек

| Слой | Выбор | Почему |
|---|---|---|
| Платформа | Expo SDK 57 (RN 0.86, React 19.2.3) | быстрый старт, OTA-обновления |
| Навигация | expo-router (file-based) | стандарт для Expo |
| Стилизация | NativeWind 4.2 + Tailwind 3.4 | палитра ТЗ в конфиге, совпадает с фронтендом в этом же репо |
| Серверный стейт | TanStack Query | кэш, ретраи, offline из коробки |
| Клиентский стейт | Zustand | лёгкий, без бойлерплейта |
| HTTP | axios | интерцепторы для токенов |
| i18n | i18next + react-i18next + expo-localization | UZ/RU на 1-м этапе |
| Видео | expo-video | |
| Токены | expo-secure-store | |
| Платежи | expo-web-browser + deeplink `uzcasting://` | нативных RN SDK у Click/Payme/Uzum нет |

### ⚠️ Грабли, на которые уже наступили

**С SDK 56 expo-router несовместим с `@react-navigation/*` напрямую.** Импортировать только через `expo-router/react-navigation` (`ThemeProvider`, `useNavigation`, `useRoute`), `expo-router/js-tabs`, `expo-router/js-stack`. Прямой импорт `@react-navigation/native` роняет бандл с явной ошибкой.

**`babel.config.js` требует `babel-preset-expo` в devDependencies** — в шаблоне SDK 57 его нет, NativeWind без него не собирается.

**`app.json` → `scheme: "uzcasting"`** — обязателен для возврата из платёжного вебвью. Не удалять.

## 8. Открытые вопросы к заказчику

1. **Premium-подписка vs разовая покупка серии.** В ТЗ есть и то и другое. Даёт ли Premium доступ ко всем сериям или это разные продукты? Влияет на весь флоу оплаты и на entitlement.
   Разбор Yangi.TV обострил вопрос: там монетизация **только** подписочная (тарифы на 1/3/6 мес и год), поштучной покупки нет вообще. Скопировать их экран покупки не получится — у нас продаётся серия. До ответа экран оплаты не проектируем. См. [STRUCTURE.md §5](./STRUCTURE.md).
2. **«Стайлинг» и «Курсы и тренинги»** — нужны ли им отдельные каталоги, как у остальных 7 направлений? В V3 их нет.
3. **Узбекский: латиница или кириллица?** Документы ТЗ на кириллице, но подписи на мокапах — латиницей. Сейчас в коде латиница.
4. **Возвраты.** ТЗ упоминает refund status, но не описывает правила. Можно ли вернуть купленную серию и при каких условиях?
5. **Защита контента.** ТЗ требует «access-controlled streaming». Нужен ли DRM (Widevine) или достаточно подписанных URL с коротким TTL? Разница в стоимости и сроках существенная.
6. **Верификация (verified badge)** — кто и по каким критериям её выдаёт?
