> Заказчик просил сделать структуру «как в Yangi.TV». Этот документ — разбор их приложения
> по видеозаписи экрана (2:29, версия 3.2.0) и решение, что берём, что меняем.
>
> **Цвета Yangi.TV (красный `#E50914` + чёрный) НЕ берём.** Палитра только из ТЗ —

## 1. Что такое Yangi.TV

Обычный OTT-кинотеатр: фильмы, сериалы, аниме, мультфильмы + онлайн-ТВ каналы.
Монетизация — **подписка на срок** (тарифы), а не поштучная покупка.

Кастинга, портфолио, профилей креаторов и creator economy там нет вообще.
Поэтому Yangi.TV даёт нам структуру только для **половины** UzCasting — контентной.
Кастинговая половина проектируется по ТЗ, аналога в Yangi.TV нет.

### Как выглядит бар

Форма — из Yangi.TV, цвета — из ТЗ. Реализация: `src/components/navigation/TabBar.tsx`.

| Параметр | Значение | Откуда |
|---|---|---|
| Форма | плавающая капсула, отступ 16px от краёв и снизу | Yangi.TV |
| Фон | полупрозрачный тёмный + blur, контент просвечивает | Yangi.TV |
| Рамка | 1px, `border` `#252540` | Yangi.TV (у них светлая тонкая) |
| Высота | 62px + safe area | — |
| Раскладка | иконка сверху, подпись под ней | Yangi.TV |
| Иконки | Ionicons, контурные → залитые в активном | Yangi.TV (у них контурные скруглённые) |
| **Активный** | **Neon Purple `#7C3AED`** + подсветка под иконкой, подпись 600 | **ТЗ, мокапы V4** |
| Неактивный | `text-muted` `#9A9AB8` | — |

⚠️ Важное отличие: **в Yangi.TV активная вкладка просто белая**, акцентного цвета нет вообще. Мы берём purple из ТЗ — на мокапах V4 нижний бар нарисован именно так: активная «Бош саҳифа» фиолетовая, остальные серые. Про стили активного состояния текстом в ТЗ ничего нет, только эти мокапы.

### Переключение

- Вкладка: цвет иконки и подписи перетекают за 180мс, активная иконка приподнимается на 2px, под ней проявляется мягкая подсветка purple (18% непрозрачности). ТЗ: «glow эффекты в меру» — поэтому подсветка слабая, а не полноценный неон.
- Экран: `animation: 'fade'` в `Tabs` — плавное перетекание вместо резкой подмены.
- Анимации на `Animated` из react-native, не на Reanimated: для микро-взаимодействия хватает, а зависимостей меньше.

Так как бар плавающий, экраны получают снизу отступ на его высоту — `useTabBarHeight()` в `Screen`, иначе последний блок уезжает под капсулу.

## 3. Экраны Yangi.TV — детальный разбор

### 3.1. Asosiy (главная)

Вертикальный скролл из независимых блоков:

1. **Хедер** — логотип по центру, без поиска и без иконок
2. **Круглые «истории»** — горизонтальный ряд аватаров с подписями (промо новинок).
   ~40px круг, подпись в 1 строку с обрезкой
3. **Hero-баннер** — крупный постер с названием под ним, свайпается (карусель)
4. **Janrlar** — горизонтальный ряд жанровых плиток с фоновой картинкой и текстом поверх
5. **Тематические рельсы** — их много, все по одному шаблону:
   заголовок слева + `Barchasini ko'rish ›` справа, под ним горизонтальный список постеров

Рельсы в записи: `Tarjima kinolar`, `Horij seriallari`, `Hind kinolar`, `Turk seriallari`, `Koreya seriallari`, `Animelar`, `Multfilmlar`, `Retro filmlar`, `O'zbek seriallari`.

**Карточка-постер** (базовый компонент всего приложения):
вертикальный постер ~2:3, бейдж в правом верхнем углу (`PREMIUM` красный / `Bepul` серый), название под постером в 1–2 строки.

> Состав и порядок рельсов явно приходят с бэкенда — это лента блоков, а не захардкоженный экран. Нам нужно то же самое: главная как массив типизированных блоков, иначе каждую правку витрины придётся выпускать через стор.

### 3.2. Qidiruv (поиск)

- Заголовок `Qidiruv` + поле поиска с иконкой
- Валидация: `Minimal qidiruv uzunligi 2 ta harf!` — красным под полем, при вводе < 2 символов
- Результаты — **список строк** (не сетка), каждая строка:
  постер-миниатюра слева, справа название, бейдж `PREMIUM`, год, `Yosh chegarasi 18+`, жанры через запятую, красная кнопка `TOMOSHA QILISH`
- Поиск живой, результаты обновляются по мере ввода

### 3.3. To'plam (подборки)

Два сегмента сверху: `To'plam` | `Janrlar`

- **Janrlar** — сетка 3 колонки, плитка = картинка + название жанра поверх
- **To'plam** — сетка 2 колонки, плитка = «стопка» из нескольких постеров веером + подпись
  (`Goblin dublyajda`, `Kosmosga sayohat`, `Parallel olam`, `O'tmish va kelajak`, `Dinozavrlar haqida`, `Robotlar`)

Тап по плитке → экран списка: стрелка назад + название + сетка постеров в 3 колонки.

### 3.4. TV (онлайн-ТВ)

- Заголовок `Onlayn TV`
- Горизонтальные скроллящиеся табы категорий: `Barchasi`, `Milliy`, `Setanta`, `Kino`, `Yangiliklar`, `Bolalar uchun`, `Ta'lim va ilm-fan`, `Sport`, `Ko'ngil ochar`, `Musiqiy`, `Hujjatli`, `Moda va uslub`, `Rus tili`, `Turkiy`, `Jahon`
- Сетка 3 колонки: белая карточка с логотипом канала + бейдж `BEPUL` + название под карточкой

**У UzCasting этого экрана нет.** Паттерн «горизонтальные табы + сетка» переиспользуем для каталогов креаторов (10 направлений из ТЗ).

### 3.5. Карточка контента (detail)

Самый насыщенный экран, копируем структуру почти целиком:

1. Размытый кадр-подложка на весь верх, поверх — круглая кнопка Play
2. Стрелка назад слева, сердечко (избранное) справа
3. Постер + справа: название, оригинальное название, `7-qism` для сериалов
4. Мета-таблица в две колонки: `Tili`, `Yili`, `Davlati`
5. Ряд из 4 статистик: 👍 `1122` · 👎 `115` · ★ `8.3/10 IMDB` · `Davomiyligi 45 daqiqadan`
6. Крупная красная кнопка `TOMOSHA QILISH` + зелёная кнопка скачивания рядом
7. `Janri:` — чипы жанров
8. `Film haqida qisqacha:` — описание
9. `Rejissyor:` / `Rollarda:` — горизонтальный ряд круглых аватаров с именами
10. `Lavhalar:` — горизонтальный ряд кадров из фильма
11. `Boshqa filmlar:` — рельс похожего контента

Есть ещё лёгкая версия — модалка поверх главной (крестик, трейлер, `TOMOSHA QILISH`).

Карточка профиля сверху: аватар + `Ismingiz`, `Tel. raqami`, `Balans: 0 UZS`, `ID: 1870181` с кнопкой копирования.

## 4. Первый вход (макет заказчика, 14.08.2026)

Заказчик прислал макет трёх экранов первого запуска. **Это источник истины по
раскладке** — приоритетнее наших прежних решений по этим экранам.

| Экран | Что на нём | Файл |
|---|---|---|
| **S01 Splash** | логотип в рамке с неоновым свечением, подпись `Ijodkorlar uchun platforma`, три точки + `loading`. Держится 1–2 сек | `src/components/SplashOverlay.tsx` |
| **S02 Onboarding** | `Skip` справа сверху, иллюстрация, заголовок, подзаголовок, точки, крупная кнопка. 3–4 слайда: casting · premyera · creator daromadi | `app/onboarding.tsx` |
| **S03 Kirish** | логотип сверху, `Iltimos, telefon raqamingizni kiriting`, поле `+998 │ 91 123 45 67`, `— yoki —`, Google, согласие ссылками, `DAVOM ETISH` | `app/(auth)/sign-in.tsx` |

```
запуск → S01 Splash ─┬─ первый раз ──────→ S02 Onboarding → S03 Kirish → Home
                     ├─ есть токен ──────→ Home
                     └─ презентацию видел → S03 Kirish
```

Признак «презентацию показывали» лежит в SecureStore
(`features/onboarding/store.ts`). Со второго запуска S02 не появляется.

### Почему splash — оверлей, а не маршрут

Отдельным экраном он занял бы `/`, а этот путь уже принадлежит `(tabs)/index`.
Плюс splash остался бы в истории переходов, и «назад» с логина возвращало бы на него.
Поэтому он лежит поверх навигатора и снимается, когда решено, куда вести.

### Что отступает от макета и почему

| Место | Макет | У нас | Причина |
|---|---|---|---|
| Кнопка на S02 | всегда `BOSHLASH` | `KEYINGI` на слайдах 1–3, `BOSHLASH` на последнем | На макете нарисован один кадр. Постоянный `BOSHLASH` делал бы слайды 2–4 недоступными ничем, кроме свайпа |
| Иллюстрации S02 | `[ cinematic illustration ]` | градиент из палитры + иконка темы | Реальных иллюстраций нет. Место и пропорции те же |
| Форма кнопок | скруглённый прямоугольник | так же, через `shape="card"` | Общий `Button` остался пилюлей: экраны вне макета не переверстываем без решения заказчика |

Гостевого входа («Keyinroq») на S03 больше нет — на макете его нет.

### Языки

Три: **узбекский по умолчанию**, русский, английский. ТЗ относило английский
ко 2-му этапу, но заказчик попросил сразу — держим с первого релиза.

Переключатель — сегментированный контрол в Профиле (`LanguageSwitcher`).
Выбор запоминается, применяется до снятия splash, иначе первый экран
мигает узбекским. Наборы ключей во всех трёх файлах обязаны совпадать:

```bash
node -e "const L={uz:require('./src/i18n/locales/uz.json'),ru:require('./src/i18n/locales/ru.json'),en:require('./src/i18n/locales/en.json')};const f=(o,p='')=>Object.entries(o).flatMap(([k,v])=>v&&typeof v==='object'?f(v,p+k+'.'):[p+k]);const b=f(L.uz);for(const k of ['ru','en']){const m=b.filter(x=>!f(L[k]).includes(x));console.log(k, m.length?'нет: '+m:'ок')}"
```

Хранилище состояния (язык, флаг онбординга) — `src/lib/storage.ts`.
Это обёртка над SecureStore с запасным localStorage для веба: нативного
модуля в браузере нет, и без обёртки веб-превью зависало на первом экране.
**Токены через неё не проводим** — им нужен именно Keystore/Keychain.

## 4.1 Регистрация — исходный разбор

Со скриншота `photo_2026-08-13_11-14-13.jpg`:

- Заголовок `Iltimos, telefon raqamingizni kiriting`
- Одно поле: иконка телефона + префикс `+998` + маска `91 123 45 67`
- Внизу — согласие с ссылками: `Foydalanuvchi kelishuvi` и `Maxfiylik siyosatiga` (выделены цветом, кликабельны)
- Одна крупная кнопка `DAVOM ETISH` внизу экрана
- Больше на экране ничего нет — ни пароля, ни соцсетей, ни «уже есть аккаунт»

Один экран = одно действие. Дальше идёт OTP.

### Наш флоу (решено с заказчиком: телефон **или** Google)

```
Телефон:  Ввод +998 → OTP-код → [если новый] имя и язык → Home
Google:   Кнопка «Войти через Google» → OAuth → Home
```

**Телефон в Google-ветке не спрашиваем.** Сначала сделали наоборот, со ссылкой на ТЗ —
ссылка оказалась неверной. Что там на самом деле:

| Документ | Формулировка |
|---|---|
| `UzCasting_UI_UX_Texnik_Topshiriq.pdf` | «Telefon/**email** орқали аккаунт яратиш. Google/Apple/Telegram каби қулай кириш вариантлари» |
| `..._V3.pdf`, экран 03 | «Telefon + OTP, parol, til tanlash, shartlarga rozilik» · «Google / Apple / Telegram **optional**» |

Аккаунт по email разрешён прямо, а соцвход назван альтернативой, а не довеском
к номеру. Требовать телефон сразу после Google — барьер, который мы придумали сами.

Номер по-прежнему нужен для выплат креаторам и для платёжных систем, завязанных
на него, — попросим в этих местах, а не на входе.

Согласие с офертой и политикой — на первом экране, как у Yangi.TV. Требование ТЗ («Maxfiylik va foydalanish shartlariga rozilik») закрывается здесь же.

Отличия от Yangi.TV: добавляем Google. ТЗ упоминает ещё Apple и Telegram как опциональные — Apple понадобится на 2-м этапе (Apple требует Sign in with Apple, если есть другие соцлогины).

## 5. Главное расхождение: подписка vs поштучная покупка

Это самый важный вывод из разбора.

| | Yangi.TV | UzCasting по ТЗ |
|---|---|---|
| Модель | подписка на срок (1/3/6 мес, 1 год) | **5 000 сум за одну серию** |
| Бейдж на контенте | `PREMIUM` / `Bepul` | `locked` / `purchased` |
| Что открывает покупка | весь каталог тарифа на срок | одну конкретную серию навсегда |
| Экран покупки | список тарифов | оплата конкретной серии |

**Структуру карточки тарифа копировать нельзя** — у нас продаётся серия, а не доступ к каталогу.

При этом в ТЗ параллельно есть и раздел `Premium` с подпиской. То есть у UzCasting монетизация двойная, и как эти две модели сочетаются — не описано. **Это вопрос №1 заказчику** (см. [ROADMAP.md §8](./ROADMAP.md)). До ответа экран оплаты не проектируем.

Что можно взять из Yangi.TV уже сейчас — экран **выбора платёжной системы** (сетка логотипов). Он одинаков для обеих моделей и совпадает со списком провайдеров из ТЗ (Click, Payme, Uzum, UZCARD, Visa, Mastercard).

## 6. Карта экранов UzCasting

Структура Yangi.TV, наложенная на сущности ТЗ:

```
(tabs)
├── Bosh sahifa                 ← Asosiy Yangi.TV
│   ├── хедер с логотипом + поиск (в ТЗ поиск на главной, не вкладка)
│   ├── круглые «истории» → популярные креаторы
│   ├── hero-карусель → премьера дня
│   ├── ряд направлений → 10 категорий из ТЗ (паттерн Janrlar)
│   ├── рельс «Bugungi premyeralar»
```

## 8. Чего в записи не было

Не попало в кадр, нужно уточнить или отдельно посмотреть:

- **Полноэкранный плеер** — управление, качество, субтитры, «следующая серия». В ТЗ требования есть, в записи экран не открывали
- **Флоу оплаты целиком** — от `Sotib olish` до подтверждения. Видно только выбор системы, не видно возврата из платёжного вебвью и экрана успеха/ошибки
- **Экран OTP** — есть только ввод телефона
- **Пустые состояния и ошибки** — аккаунт в записи с балансом 0, но пустых списков не показывали
- **Онбординг** — запись начинается с уже авторизованного пользователя

Если попадётся — запиши ещё раз эти места, особенно плеер и оплату.
